## 9. Вывод

По сравнению с ПР1 код стал заметно структурированнее: логика вынесена в task-service.js в виде чистых функций, данные — в data.js, демонстрация — в main.js, проверки — в checks.js. Каждая функция возвращает значение (объект задачи, массив названий, объект статистики, { ok, tasks }/{ ok: false, error }), а не печатает результат — это делает код пригодным для автотестов.

Неизменность данных проверена через сравнение исходного demoTasks/variantTasks до и после всех операций: функции работают по принципу immutable update — копируют массив (map, filter, spread) и изменяемую задачу ({...task}). Это устраняет побочные эффекты.

Эксперимент 3 из functions-and-references.js наглядно показал разницу между ссылкой (alias = product) и поверхностной копией ([...products], {...product}): первая меняет исходный объект, вторая защищает только верхний уровень. Эксперимент 6 уточнил поведение параметров по умолчанию — дефолт срабатывает только при undefined, а null и "" считаются заданными значениями. Ошибок, требующих исправления в текущей версии заготовки, не обнаружено; для полноты отчёта описан случай с мутирующим push и его замена на return [...arr, item].
