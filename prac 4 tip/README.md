## Эксперименты с формой и хранилищем
1. Пустое обязательное поле
   Прогноз: Форма не отправится.
   Результат: Появилась нативная подсказка браузера.
   Объяснение: Сработал атрибут required.
2. Название из пробелов
   Прогноз: Форма отправится (пробелы — символы).
   Результат: Появилась прикладная ошибка под полем.
   Объяснение: Сработал setCustomValidity в validateTaskDraft.
3. Типы значений FormData
   Прогноз: Все значения будут строками.
   Результат: id имеет тип string.
   Объяснение: FormData всегда возвращает строки.
4. Строка в localStorage и JSON
   Прогноз: Сохранится строка JSON.
   Результат: В localStorage лежит строка, которая парсится в объект.
   Объяснение: Используется JSON.stringify и JSON.parse.
5. Повреждённый JSON
   Прогноз: Ошибка SyntaxError.
   Результат: Ошибка перехвачена, загружен исходный набор.
   Объяснение: Функция loadTasks использует try/catch.

## Организация кода
- task-service.js — чистая бизнес-логика.
- form-validation.js — чистая функция валидации.
- task-storage.js — изолирует работу с localStorage.
- task-view.js — создание DOM-элементов.
- main.js — связывает всё вместе.

Функции хранения получают объект storage аргументом для тестирования без реального браузера. Данные из JSON проверяются, чтобы приложение не ломалось при ручном изменении localStorage.
